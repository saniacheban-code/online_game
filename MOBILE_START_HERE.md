# Учебная арена Mobile 1.4

## Что добавлено

«Спринт знаний»: двое бегунов, дистанция 400 м, независимые вопросы. Нужно определить, верен ли предложенный ответ на вопрос. Верный ответ ускоряет, ошибка снижает скорость; скорость действительно определяет пройденное расстояние. Без ответов бегун не стартует. Есть беговая анимация, эффекты разгона и спотыкания, скорость в м/с, дистанция, таймер, пауза и черновик. В дуэли лимит 3 минуты; первым финишировавший побеждает, по истечении лимита — пробежавший дальше. Соло: один бегун, 4 минуты и помощник по текущему заданию. Все 18 предметов подключены.

Рейтинг во всех играх: награда своего класса +10, ошибка −5. Для другого класса награда +5/+4/+3/+2/+1 в зависимости от разницы классов; штраф соответственно −2,5/−2/−1,5/−1/−0,5. Дробные баллы не округляются, счёт может быть отрицательным. Штрафы входят в общий и предметный рейтинги, в месячный итог. Истёкший таймер, который игра считает ошибкой, также передаётся как ошибка. Старые сохранённые строки Scores и уже выбранные победители месяцев не пересчитываются. Ранее неотправленные события применяются по текущему правилу при получении сервером.

Штраф 50% уменьшает выгоду случайного выбора, но математически не исключает её при двух вариантах: при случайных ответах ожидаемый результат +25% награды. Здесь реализован именно заданный штраф 50%. Ограничение частоты положительных начислений также сохранено; ошибки списываются без этого ограничения.

## 1. Обновить существующий сервер

1. Откройте прежний проект Google Apps Script, который уже подключён к базе учеников.
2. Откройте backend/google-apps-script/Code.gs из архива или отдельный Arena_Mobile_1_4_Code.txt обычным текстовым редактором. Скопируйте только код целиком.
3. В редакторе Apps Script замените содержимое Code.gs этим кодом. Не вставляйте тройные кавычки или разметку Markdown. Сохраните.
4. «Начать развертывание» → «Управление развертываниями» → выберите текущее веб-приложение → карандаш → «Версия: Новая версия» → «Развернуть». Тип — веб-приложение; запуск от вашего имени; доступ «Все». Сохраните существующий URL /exec.
5. Откройте прежний URL /exec: должны быть version:5, ready:true, wrongAnswerPenalty:0.5.

При уже работающей базе setup повторно выполнять не нужно. Не создавайте новую таблицу или новый проект, не удаляйте SPREADSHEET_ID, AUTH_PEPPER и старые листы. Структура таблиц и appsscript.json не изменены. Сессии учеников сохраняют срок до 7 дней; повторный вход из-за обновления не требуется. Если это первая установка, вставьте также appsscript.json из архива, один раз выполните setup и дайте разрешения, затем опубликуйте веб-приложение.

## 2. Обновить GitHub Pages

Распакуйте полную сборку в локальную папку репозитория с заменой файлов. В GitHub Desktop выполните Commit → Push origin. Дождитесь завершения Pages workflow и обновите страницу (Ctrl+F5 на ПК). На телефоне закройте и откройте вкладку заново. URL сервера уже указан в mobile/config.js; если используете переменную ARENA_API_URL в GitHub, она должна указывать на тот же обновлённый /exec.

Для нового APK запустите существующую Android-сборку GitHub Actions. Версия приложения 1.4.0, versionCode 8. Готовый бинарник в архив не включён.

## Проверка после публикации

Войдите, выберите свой класс: за верный ответ ожидается +10, за неверный −5. Для соседнего класса: +5/−2,5. Дождитесь синхронизации и откройте рейтинг сверху. В новой игре проверьте, что два игрока отвечают независимо, а в соло нет панели соперника. Подсказка меняется вместе с вопросом.

Подробности проверки — docs/release-1.4.md, графика — docs/sprint-art.md.
