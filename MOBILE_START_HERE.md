# Учебная арена Mobile 1.3.1

18 предметов, 17 игр, режимы на одного и двоих. Полная сборка для GitHub Pages и исходники Android-приложения.

## Обновление 1.3.1: прокрутка и ввод

Если сервер уже работает (API 4, ready:true), Apps Script, setup и таблицы менять не нужно.
Замените файлы проекта из полной сборки, выполните Commit → Push origin и дождитесь GitHub Pages. На ПК обновите страницу через Ctrl+F5; на телефоне закройте и снова откройте вкладку. Все ссылки на ресурсы меню обновлены до 1.3.1.

Список игр прокручивается при включённом «Вместить». В башнях, осаде, лабиринте и игре с блоками доступны поля ответа и экранные клавиатуры; при нехватке места используется прокрутка. Открытие системной клавиатуры учитывается в высоте встроенной игры. В лабиринте добавлен ввод с обычной клавиатуры и отправка Enter.

Для Android после обновления исходников соберите новый APK через существующий workflow. Версия приложения 1.3.1, versionCode 6.

## Возможности версии 1.3

- Кнопка «Рейтинг» сверху в меню и внутри игры. Можно выбрать общий рейтинг или один из 18 предметов, период «За месяц» / «За всё время» и архив победителей.
- Сервер учитывает предмет уже сохранённых результатов: старые баллы не нужно переносить или начислять заново.
- Общий учебный помощник различает вычисленный разбор, план решения и пример применения правила. Он не выдаёт общий совет за выполненное вычисление.
- Исправлен подбор правил к математическим вопросам, в том числе к геометрии начальной школы; уточнены неоднозначные формулировки.
- В языках добавлено применение ответа в контексте и сравнение ошибочного написания с правильным. В истории уточнены предметные пояснения к 90 записям.
- В начальной школе объясняются оба пункта составного задания. Для чтения приводится опора из самого текста; для подсчёта букв/слогов/элементов — перечисление.
- В заданиях на соответствия разбираются верные и ошибочные пары по таблице определений.
- В числовом вводе поддержаны периодические дроби, π, корни, степени и научная запись. Защита от деления на ноль и ложного принятия нуля вместо очень малого числа. Диапазон лет не превращается в арифметическое вычитание. Дополнительные символы в башнях и осаде убраны под раскрывающуюся строку.

## Только для старого сервера (API ниже 4) или первой установки

1. Откройте тот же проект Google Apps Script, которому принадлежит действующий адрес /exec. Не создавайте новый проект и не удаляйте Google Таблицу.
2. В Code.gs полностью замените код содержимым backend/google-apps-script/Code.gs из архива. Полный текст также дан в ответе в чате.
3. В настройках проекта включите показ appsscript.json. Вставьте настройки из backend/google-apps-script/appsscript.json. Разрешения: таблицы и script.scriptapp; среда V8.
4. Сохраните, выберите функцию setup и нажмите «Выполнить». Разрешите доступ, если Google запросит. Не запускайте doPost вручную.
5. В журнале должно появиться «База настроена: …». Setup сохраняет существующую базу, секрет AUTH_PEPPER, пользователей и баллы. Добавляется столбец subject на листе MonthlyWinners.
6. Развернуть → Управление развертываниями → действующее развертывание → карандаш → Версия: Новая версия → Развернуть. Запуск от вашего имени, доступ «Все». Сохраните прежний URL.
7. Откройте /exec: ожидается version: 4, ready: true, monthlyAutomatic: true. Если версия 3 — обновлённый код ещё не опубликован по этой ссылке. Если ready:false — setup не завершён.

Не меняйте вручную SPREADSHEET_ID и AUTH_PEPPER. Не публикуйте Google Таблицу или Script Properties.

## Обновление GitHub

1. Распакуйте полный архив и скопируйте его содержимое в локальную папку репозитория с заменой файлов, сохраняя структуру папок.
2. GitHub Desktop → Commit to main → Push origin.
3. Дождитесь зелёного завершения GitHub Pages в Actions. Если в настройках репозитория задана ARENA_API_URL, она должна содержать действующий адрес /exec.
4. Откройте сайт и обновите через Ctrl+F5. Проверьте вход, запуск игры, верхнюю кнопку рейтинга и переключение предмета.

Ссылка сервера в mobile/config.js сохранена прежней. Аккаунты и баллы остаются в Google Таблице.

## Рейтинг и месячный конкурс

- Общий рейтинг складывает баллы всех предметов. Предметный рейтинг использует только результаты соответствующего предмета.
- Полная награда за правильное задание своего класса — 10. Разница классов 1 / 2 / 3 / 4 / 5 и более даёт 5 / 4 / 3 / 2 / 1 балл. Ошибка — 0. Игровая энергия и победы отдельно в рейтинг не переводятся.
- Между зачтёнными ответами одного аккаунта — не менее 5 секунд во всех играх. В дуэли аккаунт получает баллы за игрока 1; второй игрок — гость. Для разных аккаунтов нужны отдельные устройства.
- Пароль от 6 символов, обязательные фамилия, имя и класс. Фамилия и имя публично видны в рейтинге. Старым незаполненным профилям предлагается заполнение с сохранением баллов.
- Месяц определяется по серверному времени Казахстана (Asia/Qyzylorda). Офлайн-результат относится к месяцу, когда сервер его принял.
- При равенстве баллов выше тот, кто раньше достиг итоговой суммы; затем стабильный порядок идентификаторов.
- Первого числа таймер сохраняет общего победителя и победителей по предметам; повторный запуск не дублирует архив. Если результатов нет, победитель не назначается. Общие очки не обнуляются.
- Старые строки архива без subject сохраняются как общий рейтинг. Предметные победители закрытых до обновления месяцев задним числом не назначаются.
- При отсутствии ответа сервера за 8 секунд игра открывается тренировкой без рейтинга. Для возобновления рейтинга нужно открыть тему заново после восстановления связи.
- Это учебный рейтинг: правильность ответа определяется приложением на устройстве. Для защищённого призового соревнования нужна серверная выдача заданий и проверка самих ответов.

## Проверки и границы

Команды: npm test, npm run audit:learning, npm run check. Отчёт по всем предметам и темам — docs/learning-audit.md и docs/learning-audit.json. Проверено 56 059 сгенерированных заданий, 1834 тематические записи; наблюдалось 836 математических идентификаторов шаблонов. Числовые задачи, языковые банки, чтение, адаптеры игр, Python/SQL/графы и рейтинг проверяются отдельными наборами тестов.

Автоматические проверки и исправление обнаруженных методических проблем не являются независимой экспертизой каждого факта банка. В математике часть вопросов сопровождается планом и разобранным учебным примером вместо автоматически вычисленного решения именно текущего варианта; это явно подписано в помощнике. Авторский игровой отбор не объявляется полным КТП.

Визуально проверены меню, помощник и переключение рейтингов на ПК и ширине 390px. Проверка интерфейса использовала демонстрационные данные: в действующую таблицу тестовые аккаунты и очки не записывались. Новый сервер владелец устанавливает самостоятельно по инструкции выше.
