Учебная арена Mobile 1.4 — штрафы и «Спринт знаний»

ВАЖНО: в этом обновлении нужно обновить и сайт, и Apps Script.
1. В прежнем проекте Apps Script замените Code.gs кодом из backend/google-apps-script/Code.gs или отдельного TXT. Сохраните.
2. Управление развертываниями → карандаш у текущего веб-приложения → Новая версия → Развернуть. Тот же URL /exec должен показать version:5, ready:true.
3. Замените файлы сайта в локальном репозитории → Commit → Push origin.
4. Дождитесь GitHub Pages, обновите страницу. Для Android соберите новый APK.

Работающую таблицу и аккаунты сохраняйте. Setup повторно не нужен, если база уже работает.
За ошибку снимается ровно половина награды, в том числе дробные значения. Счёт может быть отрицательным. Старые баллы не пересчитываются.
