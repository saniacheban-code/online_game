Учебная арена Mobile 1.3

1. Сначала обновите Apps Script: Code.gs и appsscript.json, выполните setup и опубликуйте новую версию существующего развертывания. Ожидается API 4, ready:true.
2. Замените файлы проекта в локальном репозитории, Commit → Push origin.
3. После GitHub Pages обновите сайт через Ctrl+F5.

Полная инструкция — MOBILE_START_HERE.md. Отчёт проверки всех тем — docs/learning-audit.md.
