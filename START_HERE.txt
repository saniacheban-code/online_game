Учебная арена Mobile 1.3.2 — запомнить вход

Сервер и Google Таблицы менять не нужно.
1. Замените файлы проекта в локальном репозитории. Commit → Push origin.
2. Дождитесь публикации GitHub Pages и обновите страницу (Ctrl+F5 на ПК).
3. При входе отметьте «Запомнить вход на этом устройстве». Либо включите её в профиле, если уже вошли.
4. Для Android соберите обновлённый APK через существующий workflow.

Пароль не сохраняется. Вход работает до выхода или истечения серверной сессии — до 7 дней. Без отметки вход остаётся только в текущей сессии браузера. Кнопка «Выйти» удаляет сохранённый вход даже без интернета.

Прокрутка и ручной ввод из 1.3.1 сохранены. Полная инструкция — MOBILE_START_HERE.md.
