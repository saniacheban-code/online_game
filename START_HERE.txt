Учебная арена Mobile 1.4.1 — объяснение во всех играх

1. Замените файлы проекта в локальном репозитории → Commit → Push origin.
2. Дождитесь GitHub Pages. Обновите страницу: Ctrl+F5 на ПК; закройте и откройте вкладку на телефоне.
3. Кнопка «Объяснение» находится сверху в каждой игре — в соло и дуэлях. Правило и пример относятся к текущему вопросу.
4. В дуэли выберите игрока; в «Гонке знатоков» — нужную полосу. Разбор можно прокручивать.
5. Для приложения Android соберите новый APK.

Если сервер уже работает на API 5, скрипт и таблицы менять НЕ НУЖНО. Штрафы из 1.4 и запоминание входа сохранены. Если остался API 4, переход описан в MOBILE_START_HERE.md.
