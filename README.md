# Учебная арена Mobile 1.1

18 предметов, 17 игр, мобильный интерфейс, аккаунты и рейтинг, Android APK/AAB через GitHub Actions. Контрольная GitHub 3.0 сохранена отдельно.

**Сначала прочитайте [MOBILE_START_HERE.md](MOBILE_START_HERE.md).** Обновите серверный Code.gs, выполните setup и обновите существующее веб-развертывание. Ссылка /exec сама по себе базу не настраивает.

Пароль от 6 символов, обязательный класс 1–11. За свой класс — 10 баллов, за другой — 1–5 в зависимости от разницы. Класс закреплён за аккаунтом. Старые аккаунты и баллы сохраняются при миграции.

`npm test` — проверки; `npm run build:web` — сайт; `npm run build:android` — Android-ресурсы. Архив содержит исходники; бинарный APK собирается в GitHub Actions.
