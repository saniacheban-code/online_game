# Учебная арена Mobile 1.4

18 предметов, 18 игр, режимы на одного и двоих. Новая игра — «Спринт знаний». Рейтинг: за верный ответ обычная награда, за неверный −50% от неё. Есть дробные и отрицательные баллы. Старые сохранённые результаты не пересчитываются.

Начните с MOBILE_START_HERE.md. Для этого обновления необходимо заменить Code.gs и опубликовать новую версию существующего развертывания Apps Script (API 5). При уже работающей базе выполнять setup повторно не требуется; ссылка /exec сохраняется.

npm test — все проверки; npm run test:mobile — мобильная оболочка, рейтинг, сервер и новая игра; npm run build:web — GitHub Pages; npm run build:android — ресурсы Android. APK собирается существующим workflow GitHub Actions.

Запоминание входа и исправления прокрутки из 1.3.1–1.3.2 сохранены. Контрольная GitHub 3.0 остаётся отдельной сборкой.
