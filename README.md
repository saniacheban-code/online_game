# Учебная арена Mobile 1.3.2

Начните с MOBILE_START_HERE.md. Проверка учебного помощника: docs/learning-audit.md. Сервер API 4, общий и предметные рейтинги.


18 предметов, 17 игр, обязательные фамилия и имя, класс 1–11, пароль от 6 символов. Месячный рейтинг, общий счёт и архив победителей. Автоматическое подведение итогов 1-го числа через Apps Script.

Начните с [MOBILE_START_HERE.md](MOBILE_START_HERE.md). В исправлении 1.3.1 работающий сервер API 4 обновлять не нужно. Для первой установки или старого API следуйте MOBILE_START_HERE.md. Не удаляйте прежнюю базу и AUTH_PEPPER. Последний URL уже внесён в mobile/config.js; проверьте также переменную GitHub ARENA_API_URL.

Контрольная GitHub 3.0 сохранена отдельно. `npm test` — проверки; `npm run build:web` — сайт; `npm run build:android` — Android-ресурсы. APK/AAB собираются в GitHub Actions, готовый бинарник в архив не входит.
