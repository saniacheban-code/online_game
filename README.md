# Учебная арена Mobile 1.0

Отдельная мобильная версия на базе итоговой GitHub 3.0: 18 предметов, 17 игр, аккаунты, общий рейтинг, Google Apps Script и сборка Android APK/AAB через GitHub Actions.

Начните с [MOBILE_START_HERE.md](MOBILE_START_HERE.md). Контрольная версия GitHub 3.0 не изменена. Для мобильной ветки создайте отдельный репозиторий. До настройки сервера игры работают гостем.

`npm test` — проверки; `npm run build:web` — сайт; `npm run build:android` — Android-ресурсы. Готовый бинарный APK получается после запуска сценария в GitHub Actions.
