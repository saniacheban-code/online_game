# Лови ошибку: строительство небоскрёба

Десятая игра общего сборника. Доступна **на двоих** во всех шести предметах: математике, физике, химии, биологии, географии и информатике. Существующие девять игр сохранены. Восьми прежним играм по-прежнему доступны оба режима, «Штурму мастерских» и строительству — режим на двоих.

## Как играть

Выберите предмет → «Два игрока» → «Лови ошибку: строительство небоскрёба» → класс → четверть → тему. Оба участника одновременно восстанавливают свои задания.

Раунд длится **150 секунд**. Сверху — общая стройплощадка и оставшееся время, снизу — независимые задания, места для вставки и фрагменты каждого игрока.

- Перетащите фрагмент в подходящий пропуск. Либо нажмите на фрагмент, затем на пропуск. Доступны обычные кнопки с Tab / Enter / пробелом.
- За каждый правильно установленный элемент к башне добавляется один **ровный этаж**. Установленный элемент блокируется.
- Неверная вставка добавляет перекошенный этаж и одну ошибку. Фрагмент возвращается, пропуск остаётся доступен — задание можно исправить.
- После **6 суммарных ошибок за раунд** башня обрушивается, игрок больше не строит. Соперник продолжает до конца общего времени.
- Побеждает сохранившаяся башня с большим числом ровных этажей. При равенстве ровных этажей выигрывает игрок с меньшим числом ошибок. При полном равенстве — ничья; два обрушения также дают ничью.
- Перекошенные этажи видны в конструкции, но не увеличивают число ровных этажей. У обрушившейся башни итоговая высота равна нулю.
- Пауза и скрытие вкладки останавливают обе стройки и общий таймер. После окончания времени новые вставки не засчитываются.

Поддержаны два одновременных указателя на разных половинах сенсорного экрана. Фрагменты одного игрока не принимаются на половине другого. Масштаб текста, полноэкранный режим, вписывание и смена предмета подключены к общим настройкам сборника. На небольшом экране режим «Вместить» можно отключить для более крупного отображения.

## Откуда берутся задания

Игра получает вопрос из выбранного предмета, класса, четверти и темы. Собственный второй банк с другими темами не создаётся.

Пять форм сборки:

1. **Вычисление** — выражение из следа решения текущей математической задачи и ответ. Используется только если ограниченный арифметический разбор подтверждает совпадение значения с правильным ответом.
2. **Формула + ответ** — пропуски в формуле текущего задания и место для его ответа.
3. **Правило + ответ** — пропуски в правиле именно текущей задачи, затем ответ на её вопрос.
4. **Фраза** — ответ на вопрос, разделённый на несколько словосочетаний.
5. **Ответ** — один недостающий числовой, символьный или короткий словесный элемент.

В блоке от одного до трёх пропусков. Есть нужные фрагменты и отвлекающие элементы. Одинаковые по тексту фрагменты взаимозаменяемы, поэтому одинаковый элемент не становится ложным только из-за внутреннего идентификатора. Сложность меняется существующим генератором после сборки полного блока; если внутри блока были ошибки, он не считается безошибочным для серии.

## Оформление

Созданы городской фон на закате, прозрачный атлас этажей, фундамента, крюка крана и двух строителей. Этажи опускаются сверху, неверные встают с наклоном, после шестой ошибки конструкция разлетается и оседает. Масштаб башен меняется с их высотой, чтобы оставались видны обе. Звук изначально выключен. Учитывается системная настройка уменьшения движения.

Также заново нарисованы **все десять иллюстраций меню** в едином стиле. Они находятся в одном атласе; для каждой карточки задан собственный прямоугольник, чтобы соседние картинки не попадали по краям. Обновление действует сразу во всех предметах и доступных режимах.

Исходные запросы и итоговые пути графики: `docs/builder-art-prompts.json`. Использован встроенный генератор изображений; атлас дополнительно очищен в режиме редактирования.

## Файлы для разработчика

- `games/builder/two.html` — оболочка на двоих.
- `games/builder/engine.js` — интерфейс, указатели, касания, клавиатура, анимации и работа с заданиями.
- `games/builder/model.js` — таймер, этажи, ошибки, обрушение и победитель.
- `games/builder/puzzles.js` — сборка пропусков из текущего задания и проверка фрагментов.
- `assets/css/builder.css` — раскладка игры.
- `assets/images/builder-city.png`, `builder-kit.png` — графика стройки.
- `assets/images/game-covers-v2.png`, `core/catalog-art.js`, `core/app.js`, `assets/css/menu.css` — обновлённое меню.

Внесение игры в `core/games.js` подключает её сразу ко всем предметам. После изменения HTML оболочек выполните `npm run build`; затем `npm test` и `npm run check`. Для публикации GitHub Pages переносится всё содержимое архива с сохранением папок. Распакованный `index.html` можно открывать и с диска.

## Проверки и пределы проверки

Автоматически проверены 9 804 задания всех шести банков, 23 710 недостающих элементов, отвлекающие фрагменты, блокировка установленных элементов и все пять форм сборки. Проверены независимость игроков, два одновременных перетаскивания, отказ от переноса на чужую половину, ошибочная вставка и повтор, шестая ошибка, продолжение соперника, таймер ровно 150 секунд, пауза, победитель, ничьи, повторный запуск и выход. Старые девять движков и банки предметов сохранены побайтно.

Визуальный запуск не проверен: доступный браузер не подключился к локальному серверу (`ERR_CONNECTION_REFUSED`). Поэтому окончательная проверка удобства размеров и живого перетаскивания на смартфоне и интерактивной панели остаётся за проверкой на целевых устройствах.
