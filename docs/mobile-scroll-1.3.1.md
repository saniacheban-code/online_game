# Mobile 1.3.1 — прокрутка и ручной ввод

Исправления:
- Меню предметов и всех 17 игр сохраняет обычную прокрутку при включённом и выключенном «Вместить».
- Автоматическое вписывание больше не сбрасывает прокрутку страницы к началу при изменении вопроса или размеров.
- Игровой контейнер и окна запуска/паузы прокручиваются, если содержимое не помещается.
- Панели ввода в башнях, осаде, лабиринте и игре с блоками не обрезаются вложенными контейнерами. Сцены сохраняют пропорции.
- В игре с блоками разрешена системная клавиатура; встроенная клавиатура сохранена.
- В лабиринте снят readonly, поддержан Enter, управление движением не перехватывает клавиши редактирования ответа.
- Высота внешнего iframe и внутреннего игрового поля учитывает visualViewport; при фокусе и изменении высоты поле ответа прокручивается в видимую часть.
- Учитывается фактическая высота панели настроек при переносе кнопок на несколько строк.

Проверка: npm test, npm run check, npm run test:mobile. В tests/mobile-scroll.cjs воспроизводятся включённое вписывание меню, переключение настройки, отсутствие сброса прокрутки, перенос панели, уменьшение viewport при открытии клавиатуры и показ активного поля. Игровые тесты проверяют ручные ответы и жизненный цикл в обоих режимах. Размеры viewport в этих проверках моделируются; визуальный прогон и проверка системной клавиатуры на физическом Android в этой среде не выполнялись.

Сервер, URL развертывания, формат аккаунтов и начисление очков не изменены. В комплекте сохранён прежний Apps Script API 4. При уже работающем сервере его повторно устанавливать не требуется.
