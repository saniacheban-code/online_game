# Штурм мастерских

Новая девятая игра подключена сразу к математике, физике, химии, биологии, географии и информатике через общий каталог `core/games.js`. Доступна в режиме **«Два игрока»**. Восемь прежних игр сохраняют оба режима.

## Сюжет и правила

На ярмарке изобретателей мастера Лев и Искра испытывают пружинные пусковые машины. Заводные совы разбирают учебные укрепления соперника. Персонажи, оформление, названия и графика созданы для этой игры.

- Два игрока решают собственные задания одновременно.
- По 8 сов на игрока на весь раунд. Верный ответ даёт прицельный запуск. Ошибка или истечение времени расходует одну сову на промах.
- Прицел «Низ / Центр / Верх» выбирает часть укрепления. Пока сова летит, повторный ответ не принимается.
- На каждое задание — минимум 90 секунд, максимум 180, с учётом времени источника.
- Числовые ответы вводятся с экранной или обычной клавиатуры. Поддерживаются отрицательные числа, запятая, точка, дроби через `/` и эквивалентные дроби. Пустой ввод и нулевой знаменатель не расходуют сову.
- Если ответ по теме текстовый или символический, в условии показан нумерованный список: игрок вводит номер подходящего ответа.
- У обоих есть независимые черновики с мелом и ластиком. Пауза останавливает оба таймера и полёты.
- После исчерпания обоих запасов сравнивается процент потерянной прочности укрепления соперника. Больший процент побеждает, равенство даёт ничью. Если один игрок потратил запас раньше, второй продолжает.
- При полном разрушении одного укрепления новые запуски прекращаются; уже начатые полёты и обрушения учитываются перед итогом.

## Разрушение

У каждого укрепления 10 деталей: деревянные стойки и балки, каменные опоры, стеклянная панель, крыша и световой сердечник. Прочность материалов различается. Повреждение оставляет всё больше трещин; сломанные детали вращаются, падают, отскакивают и могут повредить соседние. Потерявшие опору элементы обрушиваются цепочкой. Процент учитывает потерю прочности, включая частично повреждённые детали.

Физика работает с фиксированным шагом 1/120 секунды и проверкой отрезка полёта, чтобы быстрый снаряд не пролетал сквозь тонкую балку. Два укрепления зеркальны, условия одинаковы. Эффекты: след полёта, осколки материала, пыль, покачивание персонажей и краткая встряска при попадании. Звук изначально выключен.

## Файлы

- `games/siege/two.html` — оболочка.
- `games/siege/engine.js` — интерфейс, ответы, анимации и управление раундом.
- `games/siege/model.js` — полёт, столкновения, прочность, опоры и обрушение.
- `core/input-answer.js` — подготовка заданий и проверка чисел/дробей.
- `assets/css/siege.css` — оформление и адаптация размеров.
- `assets/images/siege-valley.png`, `siege-sprites.png`, `siege-cover.png` — новая графика.

Для размещения на GitHub Pages загрузите **всё содержимое архива**, сохраняя папки. Главная страница — `index.html`. Работает и запуск распакованного проекта с диска. После изменения HTML игры разработчику нужно выполнить `npm run build` для обновления оболочек локального запуска.

## Проверка

`npm test` проходит вместе с проверками всех прежних игр. Отдельные проверки новой игры: `tests/siege-model.cjs`, `tests/siege-two.cjs`, `tests/siege-subjects.cjs`. Проверены зеркальность, постепенный урон, промахи, потеря опор, падение деталей, независимость от частоты кадров, расход запаса, защита от двойного ответа, дроби, таймер, пауза, ничья, победа, повтор и выход. Проверены 9 804 задания всех шести банков, классов и тем. Ресурсы и оболочки проверены для запуска с диска и из подпапки GitHub Pages.

Визуальный запуск в доступном браузере проверить не удалось: браузер не подключился к локальному серверу (`ERR_CONNECTION_REFUSED`). Поэтому фактическое удобство размеров на смартфоне и интерактивной панели ещё требует проверки на устройствах.
