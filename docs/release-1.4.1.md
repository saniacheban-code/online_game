# Mobile 1.4.1 — объяснение во всех играх

На всех 36 страницах (18 игр × 2 режима) статически добавлена кнопка «Объяснение» в общую верхнюю панель, перед кнопкой полного экрана. Кнопка не зависит от отложенного появления нижнего помощника. На телефонах она не скрывается режимом крупной сцены; режим вписывания ограничивает только сцену.

Общий HTML-dialog расположен непосредственно в body, вне масштабируемой сцены. На телефоне занимает доступную высоту visualViewport, имеет отдельную прокрутку содержимого и крупную кнопку закрытия. В дуэлях можно выбрать игрока, в «Гонке знатоков» — полосу +1/+2/+3. При открытии выбирается фактически активная полоса. Смена задания обновляет открытый разбор, перезапуск убирает прежний вопрос. Закрытие: кнопка, Escape, системная кнопка «Назад» в APK. Кнопки ответов игры не перехватывают клавиши внутри помощника.

Существующая нижняя кнопка в соло также открывает общую панель. Боковой помощник на ПК сохранён. Таймеры игр работают по прежним правилам; отдельной паузы за просмотр объяснения это исправление не добавляет.

Данные берутся у текущего генератора, а не из отдельного общего текста. Открытие помощника не генерирует дополнительные вопросы, не отправляет ответы, не изменяет очки и штрафы, не запускает компьютер в соло. Все 18 предметов подключены к одному рендереру учебного объяснения.

Проверки: tests/mobile-help.cjs — все 36 страниц, наличие кнопки вне сцены, открытие, обновление, игрок/полоса, сброс, Escape/закрытие, неизменность количества заданий и передачи ответов. tests/mobile-help-content.cjs — все 1834 темы в обоих режимах и все 18 игр с реальными заданиями начальных и старших классов; 12 300 потоков с непустым правилом и примером. Дополнительно npm test и npm run check, прежние проверки рейтинга, ручного ввода и запоминания входа.

Проверки DOM и viewport выполняются программно; визуальный прогон на физическом Android в этой среде не выполнялся. Сервер API 5, его код, таблицы и схема начисления баллов не изменены.
