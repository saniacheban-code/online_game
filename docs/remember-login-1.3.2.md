# Mobile 1.3.2 — запоминание входа

Опция доступна при входе, регистрации и в профиле. По умолчанию выключена. В localStorage сохраняется только токен действующей сессии и разрешённые поля профиля; пароль, соль и proof исключены. Без опции используется sessionStorage. Восстановленный аккаунт проверяется серверным me; отказ AUTH удаляет сохранение, сетевая ошибка его сохраняет. Выход очищает локальный и временный токен сразу, серверный logout отправляется отдельно, очередь баллов не удаляется.

Сервер, API, срок токена (7 дней) и Google Таблицы не изменены. На устройствах с запретом хранилища выводится сообщение, если запомнить вход не удалось. Браузер может самостоятельно восстанавливать sessionStorage при восстановлении вкладок; это поведение браузера, а не постоянное хранение пароля.

Проверки: tests/mobile-session.cjs проверяет восстановление после нового запуска, опцию по умолчанию, временный вход, отказ от запоминания в профиле, отсутствие секретов в хранилище, повреждённые записи, недоступное хранилище, истечение сессии, сетевой сбой и выход офлайн. Дополнительно исполняются реальные обработчики входа/профиля/выхода из mobile/account.js с моделью DOM и сервера. tests/mobile-shell.cjs проверяет подключение session.js во всех 19 меню. Проверки прокрутки, рейтинга и игрового запуска сохранены.

На физическом Android приложение в этой среде не запускалось. Для установки новой версии APK требуется повторная сборка.
