# Mobile 1.4 — проверка изменения

Спринт: 18 предметов × нижний/старший класс × 2 режима = 72 реальных учебных потока. Проверяются верный/ошибочный ответ, блокировка повторной кнопки, независимость игроков, текущая подсказка, пауза, таймер, перезапуск, выход. Модель проверяет дистанцию как интеграл скорости, нулевую дистанцию без ответов, снижение скорости, досрочный финиш, ничью и победителя по времени. Страницы подключены в общий реестр, кэш HTML, меню, оболочку Android и серверный список игр.

Рейтинг: сервер API 5, схема таблиц остаётся версии 4. Проверяются штрафы всех 18 игр, все 11 заданных классов, половинки балла, отрицательный счёт, суммы предмета/месяца, повторные пакеты, запрет присланных клиентом points/reward, ограничение быстрых наград, сохранение старой истории при setup. Старые строки и архивы победителей не переписываются.

Регрессии: npm test; npm run check; npm run test:mobile. Сохранены проверки запоминания входа, прокрутки, клавиатур, помощников и старых игровых движков. Новый сервер нужно самостоятельно опубликовать в существующем Apps Script. Фактический сервер пользователя из среды не обновлялся. Визуальный прогон на физическом Android не выполнялся.

Важно о вероятностях: штраф 50% выполняет заданное числовое правило, но не делает любое угадывание невыгодным. Для 4 вариантов ожидаемый случайный результат −12,5% награды, для 3 — 0%, для 2 — +25% награды (без ограничения частоты положительных начислений). Самовольное изменение штрафа до 100% не применялось.
