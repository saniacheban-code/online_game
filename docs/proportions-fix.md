# Исправление сплющенной сцены

В «Строительстве небоскрёба» было два независимых искажения: вся сцена масштабировалась по ширине и высоте с разными коэффициентами; сами изображения этажей также помещались в слишком низкие прямоугольники.

Исправлено:

- Камера использует один коэффициент по обеим осям. Башни расположены по четвертям текущей ширины поля, поэтому сцена остаётся широкой без растягивания объектов.
- Каждый этаж, фундамент, строитель и крюк вписываются с сохранением пропорций исходного изображения. Размер и расстояние между этажами согласованы, этажи не превращаются в полоски.
- Фон заполняет поле с сохранением пропорций: лишняя часть обрезается, вместо сжатия по вертикали. Линия земли согласована с передним планом.
- Надписи под башнями рисуются отдельно от камеры, обычным шрифтом без искажения.
- Стройплощадка получила больше высоты, включая режим вписывания.
- Аналогичное растягивание фона устранено в «Штурме мастерских». Остальная логика этой игры сохранена.

Правила, длительность раунда, задания, ошибки, очки, обрушение и перетаскивание не менялись. Остальные восемь движков и банки шести предметов сохранены.

В браузере проверено построение трёх этажей и сравнение с пустой башней. Автоматический тест `tests/proportions.cjs` проверяет фактические вызовы отрисовки на размерах 1400×210, 1363×300, 800×400, 360×220 и 1920×420: равномерность камеры, пропорции фона и каждого спрайта. `npm test` и `npm run check` проходят. Физические смартфон и интерактивная панель отдельно не проверялись.
